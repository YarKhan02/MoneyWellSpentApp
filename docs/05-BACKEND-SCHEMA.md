# Money Well Spent — Data Model, Backend Schema and Access Policy
**Version:** 1.0 | **Local first, server Phase 2+**

## 1. Storage scope and ownership
**Phase 1:** all personal expense data resides only on the device in SQLite. No user account or network calls. **Phase 2:** remote PostgreSQL stores user-owned synced copies only after explicit sign-in/migration. **Phase 3:** groups/challenges store membership and aggregate visibility rules. Personal expenses are never directly group-readable.

### Storage categories
| Entity | Local | Server | Who can read |
|---|---|---|---|
| LocalPreferences | Yes | Minimal subset after sign-in | Device owner; on server account owner |
| Expense | Yes | After opt-in sync | Owner only; server aggregation service can compute group score |
| Category | Yes | After opt-in sync | Owner (system category names universally readable) |
| Budget | Yes | After opt-in sync | Owner only; **locked challenge cap** available only as participation metadata and for score computation |
| Group/Member/Invite | Cache Phase 3 | Phase 3 authoritative | Joined group users see allowed membership details; invites restricted |
| Challenge / Leaderboard | Cache Phase 3 | Phase 3 authoritative | Enrolled members see score summaries only |

## 2. Local SQLite tables (Drift equivalent)
```sql
CREATE TABLE local_profile (
  id TEXT PRIMARY KEY,
  base_currency TEXT NOT NULL CHECK(length(base_currency)=3),
  timezone TEXT NOT NULL,
  week_start INTEGER NOT NULL DEFAULT 1 CHECK(week_start BETWEEN 1 AND 7),
  created_at_utc TEXT NOT NULL
);
CREATE TABLE categories (
  id TEXT PRIMARY KEY,
  owner_scope TEXT NOT NULL CHECK(owner_scope IN ('system','custom')),
  name TEXT NOT NULL,
  icon_key TEXT NOT NULL,
  color_key TEXT NOT NULL,
  is_archived INTEGER NOT NULL DEFAULT 0 CHECK(is_archived IN (0,1)),
  created_at_utc TEXT NOT NULL, updated_at_utc TEXT NOT NULL,
  deleted_at_utc TEXT
);
CREATE TABLE expenses (
  id TEXT PRIMARY KEY,
  amount_minor INTEGER NOT NULL CHECK(amount_minor > 0 AND amount_minor <= 900000000000000),
  currency_code TEXT NOT NULL CHECK(length(currency_code)=3),
  category_id TEXT NOT NULL REFERENCES categories(id),
  note TEXT CHECK(note IS NULL OR length(note)<=280),
  occurred_at_utc TEXT NOT NULL,
  created_at_utc TEXT NOT NULL,
  updated_at_utc TEXT NOT NULL,
  deleted_at_utc TEXT,
  server_revision INTEGER
);
CREATE INDEX idx_expenses_active_occurred ON expenses(deleted_at_utc, occurred_at_utc);
CREATE INDEX idx_expenses_category_time ON expenses(category_id, occurred_at_utc);
CREATE TABLE budgets (
  id TEXT PRIMARY KEY,
  period_type TEXT NOT NULL CHECK(period_type IN ('week','month')),
  amount_minor INTEGER NOT NULL CHECK(amount_minor>0),
  currency_code TEXT NOT NULL,
  created_at_utc TEXT NOT NULL, updated_at_utc TEXT NOT NULL,
  deleted_at_utc TEXT
);
CREATE UNIQUE INDEX idx_active_budget_period ON budgets(period_type) WHERE deleted_at_utc IS NULL;
CREATE TABLE alert_deliveries (
  budget_id TEXT NOT NULL, period_start TEXT NOT NULL,
  threshold INTEGER NOT NULL CHECK(threshold IN (75,90,100)),
  delivered_at_utc TEXT NOT NULL,
  PRIMARY KEY(budget_id, period_start, threshold)
);
-- Phase 2: outbox_migrations and sync_metadata (below)
CREATE TABLE sync_outbox (
  mutation_id TEXT PRIMARY KEY, entity_type TEXT NOT NULL,
  entity_id TEXT NOT NULL, operation TEXT NOT NULL,
  payload_json TEXT NOT NULL, enqueued_at_utc TEXT NOT NULL,
  attempts INTEGER NOT NULL DEFAULT 0
);
CREATE TABLE sync_metadata (key TEXT PRIMARY KEY, value TEXT NOT NULL);
```
For seeded categories, use stable IDs across installs. JSON backup includes version, currency and full referenced categories. Export includes nondeleted entries unless user explicitly selects history.

## 3. Cloud PostgreSQL relational schema (Phase 2 and 3)
Representative migration: adjust OIDC subject types / provider mappings as needed. PostgreSQL `uuid` IDs generated by client or server; `timestamptz`; `bigint` money. API never accepts an owner override.
```sql
CREATE TABLE users (
  id uuid PRIMARY KEY,
  oidc_issuer text NOT NULL,
  oidc_subject text NOT NULL,
  display_name text NOT NULL DEFAULT 'Member',
  base_currency char(3) NOT NULL,
  timezone text NOT NULL,
  week_start smallint NOT NULL DEFAULT 1 CHECK(week_start BETWEEN 1 AND 7),
  created_at timestamptz NOT NULL DEFAULT now(),
  deleted_at timestamptz,
  UNIQUE(oidc_issuer,oidc_subject)
);
CREATE TABLE categories (
  id uuid PRIMARY KEY,
  user_id uuid REFERENCES users(id) ON DELETE CASCADE, -- NULL means seeded system category
  name text NOT NULL,
  icon_key text NOT NULL,
  color_key text NOT NULL,
  is_archived boolean NOT NULL DEFAULT false,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now(),
  deleted_at timestamptz
);
CREATE TABLE expenses (
  id uuid PRIMARY KEY,
  user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  amount_minor bigint NOT NULL CHECK(amount_minor BETWEEN 1 AND 900000000000000),
  currency_code char(3) NOT NULL,
  category_id uuid NOT NULL REFERENCES categories(id),
  note varchar(280),
  occurred_at timestamptz NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now(),
  deleted_at timestamptz,
  revision bigint NOT NULL DEFAULT 1
);
CREATE INDEX expenses_owner_time_idx ON expenses(user_id,occurred_at) WHERE deleted_at IS NULL;
CREATE INDEX expenses_owner_category_idx ON expenses(user_id,category_id,occurred_at) WHERE deleted_at IS NULL;
CREATE TABLE budgets (
  id uuid PRIMARY KEY,
  user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  period_type text NOT NULL CHECK(period_type IN ('week','month')),
  amount_minor bigint NOT NULL CHECK(amount_minor>0),
  currency_code char(3) NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now(),
  deleted_at timestamptz,
  revision bigint NOT NULL DEFAULT 1
);
CREATE UNIQUE INDEX budget_active_type_idx ON budgets(user_id,period_type) WHERE deleted_at IS NULL;
CREATE TABLE applied_mutations (
  user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  mutation_id uuid NOT NULL,
  applied_at timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY(user_id,mutation_id)
);
CREATE TABLE sync_changes (
  sequence bigserial PRIMARY KEY,
  user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  entity_type text NOT NULL,
  entity_id uuid NOT NULL,
  operation text NOT NULL,
  revision bigint NOT NULL,
  changed_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX sync_user_seq_idx ON sync_changes(user_id,sequence);
```

### Phase 3 tables
```sql
CREATE TABLE friend_groups (
  id uuid PRIMARY KEY,
  owner_id uuid NOT NULL REFERENCES users(id),
  name varchar(80) NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE TABLE group_members (
  group_id uuid NOT NULL REFERENCES friend_groups(id) ON DELETE CASCADE,
  user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  role text NOT NULL CHECK(role IN ('owner','member')),
  joined_at timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY(group_id,user_id)
);
CREATE TABLE group_invites (
  id uuid PRIMARY KEY,
  group_id uuid NOT NULL REFERENCES friend_groups(id) ON DELETE CASCADE,
  created_by uuid NOT NULL REFERENCES users(id),
  token_hash bytea NOT NULL UNIQUE,
  expires_at timestamptz NOT NULL,
  accepted_by uuid REFERENCES users(id),
  accepted_at timestamptz,
  revoked_at timestamptz
);
CREATE TABLE challenges (
  id uuid PRIMARY KEY,
  group_id uuid NOT NULL REFERENCES friend_groups(id) ON DELETE CASCADE,
  created_by uuid NOT NULL REFERENCES users(id),
  mode text NOT NULL CHECK(mode IN ('discipline','total_spent')),
  period_type text NOT NULL CHECK(period_type IN ('week','month')),
  currency_code char(3) NOT NULL,
  timezone text NOT NULL,
  starts_at timestamptz NOT NULL,
  ends_at timestamptz NOT NULL CHECK(ends_at>starts_at),
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE TABLE challenge_participants (
  challenge_id uuid NOT NULL REFERENCES challenges(id) ON DELETE CASCADE,
  user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  joined_at timestamptz NOT NULL DEFAULT now(),
  locked_budget_minor bigint,
  withdrawn_at timestamptz,
  PRIMARY KEY(challenge_id,user_id),
  CHECK(locked_budget_minor IS NULL OR locked_budget_minor>0)
);
CREATE TABLE user_blocks (
  blocker_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  blocked_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  created_at timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY(blocker_id,blocked_id),
  CHECK(blocker_id<>blocked_id)
);
```
**Implementation integrity checks (application transactions):** group owner must also be member with owner role; categories assigned to expense must be seeded/global or belong to expense owner; expense currency equals user's book currency; challenge participant must be current group member; locked cap must exist for discipline before start; enforce one-time invites with conditional UPDATE; forbid changing active challenge definitions. Add DB triggers/constraints where practical.

## 4. Authorization matrix
| Operation | Guest | Signed-in owner | Group member | Group owner | Non-member |
|---|---|---|---|---|---|
| Manage own local expenses | Yes | Yes | Yes | Yes | N/A |
| Cloud read/write own expenses | No | Yes | Only their own | Only their own | Only their own |
| View other's raw expense/note/category | No | No | No | No | No |
| Create group/invite | No | Create own group | No | Invite | No |
| View group member names | No | If member | Yes | Yes | No |
| Create challenge | No | If owner | No | Yes | No |
| Enroll in challenge | No | If group member | Yes | Yes | No |
| Read leaderboard aggregate | No | If enrolled member | If enrolled | If enrolled | No |
| Remove other group member | No | No | No | Yes | No |

All server endpoint DB queries scope `user_id = authenticated_user_id`; for group routes verify membership on each request. Return 404 for inaccessible owned resources. Never accept `user_id` from request body to select protected rows. Avoid blanket admin roles in app APIs. Scores are computed from server-owned records and eligibility only.

## 5. Query and retention behavior
- Period sum query uses `deleted_at IS NULL`, currency and time window. No report reads private friend expenses directly from client.
- Server computes leaderboard aggregates using privileged internal service query but only returns authorized minimal results; prefer compute-on-request first and cache only if scale demands.
- Sync tombstones retained for a documented minimum synchronization grace period; clients offline longer than retention require full reconciliation snapshot.
- For hard account deletion, cascade owned rows plus revoke groups/handle owned-group succession or dissolution, prune logs and backups per published retention policy.
- Implement explicit export and GDPR-style delete mechanisms before public cloud release; do not promise impossible instantaneous backup deletion.
